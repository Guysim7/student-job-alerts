# student-job-alerts

A tool that monitors top tech companies for new student job postings (internships, new grad roles) and sends you a notification when one is found.

## Target Companies
- NVIDIA
- Microsoft
- (more to be added)

## Features (planned)
- Scrape company career pages for student/intern/new-grad roles
- Send phone/message notifications when new jobs are posted
- Run on a schedule to check for updates
